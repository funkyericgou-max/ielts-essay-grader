# UI 与交互设计

完全复用原 HTML 的精美 UI 布局，仅针对新逻辑做如下微调：

## 布局变更

```
┌──────────────────────────────────────────────────────┐
│  Top Bar: Logo + Title + 导航链接 + 用户头像          │
├────────────┬─────────────────────────────────────────┤
│            │                                         │
│  Sidebar   │  Main Content                           │
│            │                                         │
│  - 总分概览 │  输入面板（Task Toggle + prompt + essay + 按钮）│
│  - 4 维条形图 │  或                                   │
│  - 基础统计 │  评分结果视图（5 个 Tab）                   │
│  - 高频词汇 │    - 评分总览（4 维度卡片）                  │
│  - 问题标签 │    - 作文批注（高亮标注）                    │
│            │    - 语法分析（可折叠手风琴）                  │
│            │    - 详细反馈（优/缺点 + 文章结构分析）        │
│            │    - 行动建议（3 条精准改进动作）             │
│            │                                         │
└────────────┴─────────────────────────────────────────┘
```

## 具体修改项

1. **输入面板新增 Toggle 切换**：在题目输入框上方加入两档切换按钮 `[Task 1 (小作文)]` / `[Task 2 (大作文)]`，默认选中 Task 2
2. **Tab 标签页更名**：原「训练计划」Tab 更名为「行动建议」
3. **状态保留逻辑**：点击「重新批改」时，仅隐藏结果视图、显示输入面板，完整保留用户之前输入的题目和作文，允许二刷修改
4. **Loading 体验增强**：加载动画下方滚动播放提示文案（如"正在对照官方量表进行三步定档..."、"正在扫描中式英语与搭配误用..."）

## Tab 说明

| Tab | 内容 | 数据来源 |
|-----|------|---------|
| 评分总览 | 题目分析卡片、4 维度评分卡片（分数+推理依据+证据引用） | `evaluation_justification` + `prompt_analysis` |
| 作文批注 | 带 HTML span 标签高亮的完整作文文本，直接 innerHTML 渲染 | `annotated_essay` |
| 语法分析 | 可折叠的语法问题列表，每条含原文引用、修改和语法解析 | `grammar_issues_list` |
| 详细反馈 | 优点列表、不足列表、宏观逻辑诊断文本 | `feedback` |
| 行动建议 | 3 条精准改进动作 | `next_steps` |
