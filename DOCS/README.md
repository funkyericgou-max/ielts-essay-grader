# 设计文档总纲

> IELTS AI Grader — AI 驱动的雅思写作 + 口语智能评分系统

## 项目目标

将 `index.html` 单文件应用从**写作批改工具**扩展为**写作 + 口语双模式 AI 评分工具**。

**核心挑战**：
- 写作：让 AI 评分尽可能接近雅思官方标准（±0.5 分偏差）
- 口语：在零后端、纯前端的限制下，实现录音→转写→评分的完整链路

## 核心优化策略

| # | 策略 | 说明 |
|---|------|------|
| 1 | **双模块支持** | 首页 Writing / Speaking 双入口，两套独立的评分标准和 UI |
| 2 | **Chain-of-Thought (CoT) 强制推理** | JSON 输出顺序设计为"先分析推理 → 再输出证据 → 最后给出分数"，消除幻觉 |
| 3 | **全文标签包裹法** | AI 直接返回带 HTML 安全标签的完整文本（作文/转写），前端 `innerHTML` 渲染，零高亮错位 |
| 4 | **Few-Shot Anchoring 锚定** | System Prompt 内嵌官方判定标准样文，框定评分严厉度 |
| 5 | **强制量化核对清单** | 各维度必须逐项回答定量问题，AI 才能赋分 |
| 6 | **口语音频分析** | 前端 Web Audio API 提取 WPM/停顿/音量变化，辅助 AI 评分 |
| 7 | **免费 STT 转写** | Groq Whisper 免费语音转文字，零成本 |
| 8 | **防守性编程** | Try-Catch + 正则去噪 + AbortController 超时 + Fallback textarea 兜底 |
| 9 | **教练属性** | 不只是判官，还提供逐句升级示范 + 刻意练习任务 + 行动建议 |
| 10 | **单文件部署** | GitHub Pages，无后端，API Key 仅存 localStorage，零泄露 |

## 开发流程建议

```
DOCS/*.md（设计文档）→ review → index.html（编码实现）→ examples/（验证输出）
```

先写文档再写代码。文档是便宜的（改几行字 vs 改几百行代码），设计漏洞在文档阶段发现成本最低。

## 关键术语对照

| 缩写 | 全称 | 中文 | 适用模块 |
|------|------|------|---------|
| TA | Task Achievement / Task Response | 写作任务完成/回应情况 | 写作 |
| CC | Coherence & Cohesion | 连贯与衔接 | 写作 |
| FC | Fluency & Coherence | 流利度与连贯性 | 口语 |
| LR | Lexical Resource | 词汇资源 | 写作 + 口语 |
| GRA | Grammatical Range & Accuracy | 语法多样性与准确性 | 写作 + 口语 |
| P | Pronunciation | 发音 | 口语 |
| TTR | Type-Token Ratio | 词汇类型比（衡量词汇多样性） | 写作 + 口语 |
| WPM | Words Per Minute | 语速（每分钟词数） | 口语 |
| CoT | Chain of Thought | 思维链推理 | 写作 + 口语 |
| STT | Speech to Text | 语音转文字 | 口语 |
