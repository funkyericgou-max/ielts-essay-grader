### 交互逻辑

- **左入口栏**：四个功能入口（写作 / 口语 / 听力 / 背单词）以紧凑导航项呈现，各带一条模式主题色左边框；hover 时轻微右移（`transform: translateX(2px)`）并加深边框
- 点击入口后切换到对应工作区，顶栏标题随之变化（"IELTS Essay Grader" / "IELTS Speaking Grader" / "IELTS Listening Trainer" / "IELTS Vocabulary Trainer"）
- 顶栏「← 返回首页」返回**计划页**并自动定位到当前天；顶栏始终保留「⚙ 设置」
- 入口栏底部是**学习身份**（由 `PLAN_IDENTITIES` 决定，当前只有 Sophia，显示静态标识不摆按钮），与背单词模块共用同一套身份，各有一份独立的 60 天计划
- **右侧 60 天计划**分两层：总览（按 `phases` 分三块可折叠——1–20 / 21–45 / 46–60；每块一列横条，每条 = `Day N` + 学科 tag + 进度条 + 已完成 a/b；默认只展开当前天所在阶段）→ 点横条进入单日详情
- 单日详情可增/删/上下移任务、勾选完成、单独设置当天目标时长；已排时长超出目标时整行标红
- 身份门已移除：只剩一个身份，打开即进入总览
- 入口栏**不是** Sidebar + Main 布局的一部分：它只在首页出现，四个工作区内部布局完全不变

### 移动端触控与缩放

- `html` 上设 `touch-action:manipulation` —— 允许拖动与**双指缩放**，但关掉**双击放大**（误触放大后看不到全貌的主因）。刻意不写 `user-scalable=no`：那会连用户主动的放大一起禁掉，需要放大看小字的人就用不了了
- `-webkit-text-size-adjust:100%` —— 阻止 iOS 横屏时的文字自动膨胀
- **表单控件在 ≤768px 统一 16px**：iOS Safari 对聚焦时字号 <16px 的输入框会自动放大整个页面，用户一点输入框就被放大。窄的数字框（时/分、目标时长）同步加宽到 64/56px，否则 16px 下两三位数会被挤出去
- 这条覆盖规则刻意放在**样式表最末尾**：相关类的基规则散落在文件各处（有的在后面），同权重下靠「后出现的赢」，只有放最后才能整片盖住
- 注意：`#promptInput` / `#cueCardInput` 原本把 `font-size` 写在**内联 style** 里，内联压过一切外部 CSS，媒体查询永远盖不住 —— 已挪进 CSS

### 响应式

- **≤ 1024px**：入口栏改为**网格**（`.home-rail-section` 用 `repeat(auto-fit,minmax(140px,1fr))` —— 390px 手机自然排成 2×2 四格，1024px 平板自然一行四个），隐藏重复的 `.home-rail-head` 品牌块，身份区独占一行；计划区占满整宽
- **≤ 768px**：入口栏 2×2 四格四个一屏全见；总览阶段头允许折行（标题独占一行），横条收窄间距、tag 变小——每条仍是 `Day N` → tag → 进度条 → 完成度文字（如「已完成 3 / 4」「✓ 全部完成 · 4h45m」），三态配色（未安排灰 / 进行中蓝 / 已完成青绿）；任务行折行（勾选 + 文本一行，时长 + 操作一行）；当天目标头部改纵向堆叠

### 侧边栏抽屉（≤1024px）

四个工作区在 ≤1024px 时侧边栏变成固定定位的滑出抽屉，由顶栏的 ☰ 切换。

> ⚠️ **别把 `.sidebar` 的基础规则移到 `@media(max-width:1024px)` 之后**。曾经基础规则里的 `position:sticky` 排在媒体查询的 `position:fixed` 后面，同权重下把移动端设定压掉了：侧边栏没有滑出屏幕，而是在网格里占满一整行（787px 高），把 `main` 挤到 y≈870 —— 四个工作区在手机上全部一片空白。参见 `CLAUDE.md` 的「改 CSS 时的顺序陷阱」。

#### 波形可视化

使用 Canvas + `requestAnimationFrame` 绘制实时波形：
- `AnalyserNode.getByteTimeDomainData()` 获取时域数据
- 波形颜色跟随录音状态（录制中=红色，暂停=橙色，回听=绿色）
- 非录音时显示为灰色占位线

#### 按钮状态机

```

评分中: 所有按钮禁用 + Loading 覆盖层
```

### 口语评分结果视图

#### Tab 1: 评分总览

- 题目分析卡片（cue card 主题 + 提取的核心话题）
- 4 维度评分卡片：FC / LR / GRA / P，每张卡片含分数 + 分析 + 证据

#### Tab 2: 转写批注

- 完整转写文本，AI 用 span 标签标注：
  - `.ielts-good` — 优秀口语表达（绿色下划线）
  - `.ielts-grammar` — 语法/时态口误（橙色下划线）
  - `.ielts-vocab` — 词汇误用/不地道表达（紫色下划线）
  - `.ielts-fluency` — 流利度问题：填充词、重复、自我纠正（黄色下划线）🆕
  - `.ielts-pronounce` — 可能的发音问题标注（粉色下划线）🆕
- 图例说明每种颜色的含义

#### Tab 3: 语法分析

- 与写作模式相同的可折叠手风琴组件
- 遍历 `grammar_issues_list`，每条显示原文、修正、解析

#### Tab 4: 流利度分析（🆕 口语独有）

可视化展示音频分析数据：

- **语速仪表盘**：圆形仪表盘显示 WPM 数值 + 理想区间 (120-150) 标注
- **停顿分布条形图**：时间轴上的停顿位置和时长
- **填充词统计**：各类填充词计数（um, uh, er, like, you know...）
- **综合诊断文本**：AI 生成的流利度分析

> 图表使用 Canvas 或轻量 SVG 绘制，不引入额外图表库（保持零依赖）。

#### Tab 5: 详细反馈

- 优点卡片（口语表达亮点）
- 不足卡片（需要改进的地方）
- 流利度综合诊断文本

#### Tab 6: 行动建议

- 3 条精准改进动作（同写作模式）

## 六、响应式适配

| 断点 | 布局变化 |
|------|---------|
| > 1024px | 两栏布局（Sidebar + Main） |
| ≤ 1024px | 首页卡片纵向堆叠；Sidebar 变为滑出面板，通过 ☰ 按钮切换 |
| ≤ 768px | 首页卡片全宽；口语录音按钮增大（方便拇指操作）；波形简化为音量条 |
