### 交互逻辑

- 两张大卡片 hover 时有微妙的上浮动效（`transform: translateY(-4px)` + 阴影加深）
- 点击后切换到对应工作区，顶栏标题随之变化（"IELTS Essay Grader" ↔ "IELTS Speaking Grader"）
- 顶栏新增「← 返回首页」按钮，允许用户切换模式
- 模块入口卡片**始终可见**（不在 Sidebar + Main 的两栏布局中）

## 三、口语工作区（新增）

```
┌──────────────────────────────────────────────────────┐
│  Top Bar: ← 返回 | Logo + "IELTS Speaking Grader" | ⚙ 设置 | 👤 │
├────────────┬─────────────────────────────────────────┤
│            │                                         │
│  Sidebar   │  Main Content                           │
│            │                                         │
│  - 总分概览 │  输入面板（Cue Card + 录音区 + 提交按钮）  │
│  - 4 维条形图 │  或                                   │
│  (FC/LR/   │  评分结果视图（6 个 Tab）                   │
│   GRA/P)   │    - 评分总览（4 维度卡片）                  │
│  - 口语统计 │    - 转写批注（高亮标注）                    │
│  - WPM     │    - 语法分析（可折叠手风琴）                  │
│  - 停顿     │    - 流利度分析（📊 可视化图表）              │
│  - 填充词   │    - 详细反馈（优/缺点 + 流利度诊断）         │
│  - TTR     │    - 行动建议（3 条精准改进动作）             │
│  - 问题标签 │                                         │
│            │                                         │
└────────────┴─────────────────────────────────────────┘
```

### 口语输入面板

#### Cue Card 题目区

可折叠的题目输入/展示区，支持：
- 手动输入 or 粘贴 cue card 内容
- 预设几个常见 Part 2 题目供快速选择
- 提供「加载示例」按钮（加载示例 cue card + 模拟转写文本，方便测试）

#### 录音操控区

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│     🎵 音频波形可视化 (Canvas 实时绘制)               │
│     ═══════════════════════════════════════          │
│     ████░░████░░░██████░░░░████████░░░███           │
│                                                     │
│     ⏱ 01:32 / --:--                                 │
│                                                     │
│  [🔴 开始录音]   [⏸️ 暂停]   [⏹️ 停止并保存]         │
│                                                     │
│  录音保存后：                                        │
│  [▶️ 播放回听]   [🔄 重新录制]   [📤 提交评分]       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

#### 波形可视化

使用 Canvas + `requestAnimationFrame` 绘制实时波形：
- `AnalyserNode.getByteTimeDomainData()` 获取时域数据
- 波形颜色跟随录音状态（录制中=红色，暂停=橙色，回听=绿色）
- 非录音时显示为灰色占位线

#### 按钮状态机

```
初始态: [🔴 开始录音] (可点击) [⏸️ 暂停] (禁用) [⏹️ 停止] (禁用)
录制中: [🔴 开始录音] → [录制中...] (禁用) [⏸️ 暂停] (可点击) [⏹️ 停止] (可点击)
暂停态: [▶️ 继续录制] [⏹️ 停止并保存]
保存后: [▶️ 播放回听] [🔄 重新录制] [📤 提交评分]
评分中: 所有按钮禁用 + Loading 覆盖层
```

### 口语评分结果视图

#### Tab 1: 评分总览

- 题目分析卡片（cue card 主题 + 提取的核心话题）
- 4 维度评分卡片：FC / LR / GRA / P，每张卡片含分数 + 分析 + 证据

#### Tab 2: 转写批注

- 完整转写文本，AI 用 span 标签标注：
  - `.ielts-good` — 优秀口语表达（绿色下划线）
  - `.ielts-grammar` — 语法/时态口误（橙色下划线）
  - `.ielts-vocab` — 词汇误用/不地道表达（紫色下划线）
  - `.ielts-fluency` — 流利度问题：填充词、重复、自我纠正（黄色下划线）🆕
  - `.ielts-pronounce` — 可能的发音问题标注（粉色下划线）🆕
- 图例说明每种颜色的含义

#### Tab 3: 语法分析

- 与写作模式相同的可折叠手风琴组件
- 遍历 `grammar_issues_list`，每条显示原文、修正、解析

#### Tab 4: 流利度分析（🆕 口语独有）

可视化展示音频分析数据：

- **语速仪表盘**：圆形仪表盘显示 WPM 数值 + 理想区间 (120-150) 标注
- **停顿分布条形图**：时间轴上的停顿位置和时长
- **填充词统计**：各类填充词计数（um, uh, er, like, you know...）
- **综合诊断文本**：AI 生成的流利度分析

> 图表使用 Canvas 或轻量 SVG 绘制，不引入额外图表库（保持零依赖）。

#### Tab 5: 详细反馈

- 优点卡片（口语表达亮点）
- 不足卡片（需要改进的地方）
- 流利度综合诊断文本

#### Tab 6: 行动建议

- 3 条精准改进动作（同写作模式）

## 五、响应式适配

| 断点 | 布局变化 |
|------|---------|
| > 1024px | 两栏布局（Sidebar + Main） |
| ≤ 1024px | 首页卡片纵向堆叠；Sidebar 变为滑出面板，通过 ☰ 按钮切换 |
| ≤ 768px | 首页卡片全宽；口语录音按钮增大（方便拇指操作）；波形简化为音量条 |
