# 背单词设计

## 一、功能概述

在现有 Writing（写作批改）、Speaking（口语批改）、Listening（听力同义替换）基础上，新增第四个模块 **Vocabulary（背单词）**。与 Listening 模块同构：

- **零 API 调用**：无需 DeepSeek Key、无需 Groq Key，纯客户端运行
- **零依赖**：词汇数据以 JS 常量嵌入独立文件 `vocabulary-data.js`
- **即开即玩**：点击首页卡片进入，无需任何配置
- **练习形式**：**闪卡浏览 + 间隔重复**（不做选择题测验）
- **身份选择**：进入界面先选角色（Eric / Sophia），进度彼此独立

### 核心链路

```
首页第 4 卡 → 身份选择 (Eric / Sophia)
  → 主界面（侧边栏 + 双 Tab）
      ├─ Tab1 闪卡浏览：搜索 + 分类筛选 → 翻卡看释义/例句 → 认识/不认识
      └─ Tab2 间隔重复：到期词 + 每日新词 → 三档评分(不认识/模糊/认识) → 调度下次复习
  → 侧边栏实时更新：已掌握 / 学习中 / 今日待复习 / 各分类进度
```

## 二、数据来源与数据结构

### 源

由作者逐词整理 **1000 个 G类（培训类）核心词**，按 G类 IELTS 生活/职场/书信场景分类。例句全部原创编写（含中文翻译），不照搬任何出版书，零版权风险。

### 分类统计

| 编号 | 分类 | 英文 | 词数 |
|------|------|------|------|
| 一 | 日常生活 | Daily Life | 100 |
| 二 | 工作与职场 | Work & Career | 100 |
| 三 | 住房与住宿 | Housing & Accommodation | 100 |
| 四 | 交通与出行 | Transport & Travel | 100 |
| 五 | 健康与医疗 | Health & Medicine | 100 |
| 六 | 购物与消费 | Shopping & Money | 100 |
| 七 | 教育与学习 | Education & Study | 100 |
| 八 | 环境与自然 | Environment & Nature | 100 |
| 九 | 社会与人群 | People & Society | 100 |
| 十 | 书信与观点 | Letters & Opinions | 100 |
| | **合计** | | **1000 词** |

> 第十类 `writing` 专门覆盖 G类写作 Task 1 书信（正式/非正式语气）与 Task 2 观点表达/连接词，区别于 A类学术词表。

### JS 常量结构

`vocabulary-data.js` 顶部注释定义全局常量：

```javascript
const VOCAB_CATEGORIES = [
  {
    id: 'daily',          // 分类 id
    name: '日常生活',      // 中文名
    sub: 'Daily Life',    // 英文副标题
    words: [
      { w: 'rent', pos: 'v./n.', zh: '租；租金',
        en: 'We rent a small flat near the city centre.',
        cn: '我们在市中心附近租了一套小公寓。',
        syn: 'lease' }
    ]
  }
  // ... 10 个分类，每类 100 词
];

// 扁平化（浏览/抽样/调度用）
const VOCAB_ALL_WORDS = VOCAB_CATEGORIES.flatMap(c =>
  c.words.map(w => ({ catId: c.id, catName: c.name, catSub: c.sub, ...w }))
);
```

**字段约定**：`w` 单词（全局唯一，进度按其作 key）、`pos` 词性、`zh` 中文释义、`en` 英文例句、`cn` 例句翻译、`syn` 近义词（可为空字符串）。

## 四、间隔重复机制

### 存储结构

`localStorage` key `vocab_progress`，按身份隔离：

```javascript
{
  eric: {
    daily: { level: 3, next: 1730000000000 },  // 词状态，按词 w 作 key
    // ...
  },
  sophia: { ... }
}
```

### 词状态与等级

| 字段 | 含义 |
|------|------|
| `level` | 0–5 记忆等级（0=新词未学，≥3=已掌握） |
| `next` | 下次复习时间戳（毫秒） |

### 三档评分 → 调度

| 评分 | 含义 | level 变化 | 下次复习间隔 |
|------|------|-----------|-------------|
| 😕 不认识 | 完全想不起 | 降到 0 | 10 分钟后重新排队 |
| 😐 模糊 | 想起但不熟 | 保持（≥1 时），0→1 | 1 天 |
| 🙂 认识 | 顺利想起 | +1（封顶 5） | 按等级表 |

### 等级间隔表

| level | 间隔 |
|-------|------|
| 1 | 1 天 |
| 2 | 2 天 |
| 3 | 4 天 |
| 4 | 7 天 |
| 5 | 15 天 |

### 每日新词配额

每次进入「间隔重复」Tab，先取**到期词**（`next <= now`，按时间升序），不足则补**新词**（level 0 未学）至当日配额（默认 20），避免一次灌入过多。

### 统计口径

- **已掌握** = level ≥ 3 的词数
- **学习中** = 1 ≤ level ≤ 2 的词数
- **未学** = level 0 且从未评分的词数
- **今日待复习** = 到期词数（`next <= now`）

## 五、闪卡浏览 Tab

1. **搜索**：按中文 / 英文模糊过滤
2. **分类筛选**：下拉选分类（默认全部）
3. **翻卡**：正面 `单词 + 词性`，点击翻面显示 `中文释义 + 英文例句 + 例句翻译 + 近义词`
4. **评分**：底部「😕 不认识」「🙂 认识」两按钮，写入当前身份进度（认识→level+1 并调度，不认识→level 0 重新排队）
5. **列表模式**：点分类展开逐词看完整信息（复用 `renderListeningGlossary` 模式）

## 七、与现有模块的差异

| 维度 | Writing | Speaking | Listening | Vocabulary |
|------|---------|----------|-----------|-----------|
| API 调用 | DeepSeek | DeepSeek + Groq | 无 | **无** |
| 数据来源 | AI 实时 | AI 实时 | JS 常量 | **JS 常量（独立文件）** |
| 主要交互 | 文本输入 | 录音 | 点 tile | 翻卡 + 评分 |
| 持久化 | localStorage Key | localStorage Key | 无 | **`vocab_progress`（分身份）** |
| 核心机制 | CoT 评分 | CoT 评分 | 匹配判定 | **间隔重复** |
