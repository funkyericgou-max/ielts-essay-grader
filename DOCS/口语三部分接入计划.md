## 二、接入路线图（按优先级排序的建议实施顺序）

### Step 1 · P2 → 把"思路要点卡"喂给每道真题（小）
把 Simon 的 5 类结构（人物/地点/物品/事件/活动 → 对应 `simon-lessons.js` 各课的 `points` + 好词）做成 **P2 题库的"答题思路助手"**：
- 打开某道真题时，按该题类型显示：答题骨架提示 + 该类型 Simon 好词（`highlights`/`improveWith`）。
- 数据：不动 simon-lessons.js；在 `SPEAKING_TOPIC_CATEGORIES` 每题加 `type` 字段（或前端由 category 推断）。
- 接入点：`selectSpeakingTopic()`（填题后可选展开）或题库卡片上加"思路"入口。

### Step 2 · P1 → 挂进 Simon P1 示范（中）
- `simon-lessons.js` lesson 2 的 8 道 P1 问答 = 现成 P1 示范。
- 为 Simon 任务加 `part` 意识：P2 走「填 cue → 独白录音」，P1/P3 走「QA 队列」（点示范 → 逐题跟答/录音 → 批量评分），把 `openSimonTask()` 在 P1/P3 场景也开放，但行为切到 QA 队列。
- 进度存储 `simon_lesson_progress` 建议按 part 分键或至少标注，避免跨场景错乱。

### Step 3 · P3 → 真题组 + 结构引导（中，需要内容）
- 从「躺着学雅思」那份新题 PDF 的 Part 3 例题（"What do old people usually do… / What can young and old learn from each other? / Is it always good to be a popular student?"）扩出当季 P3 主题组，追加进 `SPEAKING_PART3_TOPICS`。
- 每 P3 题可配"答题公式提示"（观点 + 理由 + 例子/对比），落在 QA 面板提示行。

### Step 4 · 语料库进工具（大，建议最后）
把三份口语资料整理成数据文件并做**按 Part 打标签**的语料库：
- `Golden Idioms`（114 个，原样偏写作/部分有误，需筛 → 保留口语化 ~60 个）
- `雅思口语必备900句`（书面腔重，只挑少量作"话题观点话料"）
- Simon 各示范里的高光词（已结构化在 `simon-lessons.js`）
- 建议不做"背诵库"，而做 **"按话题/Part 可检索的表达库"**，练到某题时可点看。

### Step 5（可选）· 学习闭环增强
- P1/P3 多题评分目前给"整场综合分"；可后续加"单题小分"回看。
- 历史练习打卡 / 每周复习（复用背单词的间隔重复思路，但按 Part 场景）。

## 三、技术接入点清单（改哪、别踩什么）

| 目标 | 主要改动位置 |
|------|-------------|
| Simon 任务按 Part 分流 | `simon-lessons.js`（每 lesson 标 `part`/适用场景）；`openSimonTask()` / `renderSimonTask()` 按 `speakingPart` 走 cue 或 QA 队列 |
| P1/P3 场景开放 Simon 入口 | UI：入口按钮从 P2 cue 行移到场景级（如 `#spPartToggle` 旁或题库按钮旁），`renderSpeakingPartUI()` 里统一显示 |
| 题库 + 思路卡 | `speaking-topics.js` 或渲染层 `renderSpeakingTopicBank()` / `selectSpeakingTopic()` |
| P3 真题扩充 | `speaking-qa-topics.js` 追加组（保持 `{id,name,icon,en,questions[]}` 结构） |
| 语料库 | 新数据文件（如 `speaking-expression-bank.js`），字段 `{part|topic, phrase, zh, example, source}`；按需 `<script>` 引入 |
| 跨场景数据一致性 | 每加数据文件同步改 `CLAUDE.md` 数据文件数与模块表；新 localStorage key 写明是否按身份/按 part |

**不要踩**：Simon 任务现有的 P2 行为（填 cue → 录音）保持不变；v5 的 `resetTransientAndSession()` / `switchSpeakingPart()` 重置逻辑别被新入口绕开；P1/P3 单题 60/120s 录音上限由 `SPEAKING_PART_CONFIG.autoStopSec` 决定，QA 队列别混入 P2 的 300s。
