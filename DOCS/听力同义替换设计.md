# 听力同义替换设计

## 一、功能概述

在现有 Writing（写作批改）和 Speaking（口语批改）基础上，新增 **Listening（听力同义替换练习）** 模块。与前两个模块完全不同，此模块：

- **零 API 调用**：无需 DeepSeek Key、无需 Groq Key，纯客户端运行
- **零依赖**：所有数据以 JS 常量嵌入 `index.html`
- **即开即玩**：点击首页卡片即刻进入，无需任何配置
- **数据来源**：`听高频同义词汇.txt`（115 组同义词对 + 陷阱词参考）

### 核心链路

```
用户选择分类范围 → 随机抽取 10 组同义词对
  → 随机选 target 词 (题干表达或音频原文侧)
  → 生成 tile grid (正确答案 + 干扰项，含中文释义)
  → 用户点选所有同义词 → 提交判定
  → 正确(绿) / 误选(红) / 漏选(灰删除线) 即时着色反馈
  → 侧边栏实时更新进度 / 正确率 / 连对 / 分类掌握度
  → 10 轮结束后展示完整结果 + 错误回顾 → 可选导出 Markdown
```

## 四、游戏机制

### 回合流程

1. **随机抽取**：从用户勾选的分类中 shuffle，取前 10 组同义词对
2. **生成 target**：随机选 target 侧（题干 q 或音频原文 a），从该侧随机挑一个词作为目标词
3. **生成选项**：
   - **正确答案** = 对侧的所有词 + 该组的中文释义 `cn`（混合中英文符合用户要求）
   - **干扰项** = 从其他对随机抽 4-6 个英文词 + 1-2 个其他中文释义
   - **shuffle** 所有选项
4. **释义提示规则**：当 target 是**英文单词**时，不显示中文释义提示（用户需要自己知道意思）；当 target 是**中文释义**时，同样不显示额外提示
5. **用户交互**：点击 tile 选中/取消，显式点击"提交答案"
6. **判定与着色**：
   - 选中的正确项 → 绿色 (`.correct`)
   - 选中的错误项 → 红色 (`.wrong`)
   - 未选中的正确项 → 灰色删除线 (`.missed`)
   - 所有 tile 变为 `.disabled` 不可再点击
7. **提交后反馈**：
   - 显示本轮结果摘要（正确/误选/漏选数量）
   - 标注漏选的具体词语
   - 显示 **[➡️ 下一题]** 按钮，**用户手动点击后**才进入下一轮
   - 不再自动跳转
8. **侧边栏更新**：进度、正确率、连对、误选/漏选、分类掌握度
9. **最后一轮提交后** → 直接展示最终结果

### 选项数量

| 类型 | 数量 |
|------|------|
| 正确答案（英文同义词） | 1-4 个 |
| 正确答案（中文释义） | 1 个 |
| 干扰项（英文） | 4-6 个 |
| 干扰项（中文） | 1-2 个 |
| **总选项** | **8-12 个** |

## 五、计分逻辑

### 每轮判定

```
对每个 tile:
  - 用户选了 且 是正确的 → correct++
  - 用户选了 且 是错误的 → wrong++，记录到 errors[]
  - 用户没选 且 是正确的 → missed++，记录到 errors[]
  - 用户没选 且 是错误的 → (不计分)
```

### 统计指标

| 指标 | 计算 |
|------|------|
| 正确率 | `correct / (correct + wrong + missed) × 100%` |
| 连对 (streak) | 连续全对的轮数（该轮 wrong+missed=0 则 streak++，否则归零） |
| 最佳连对 | 历史最高 streak |
| 分类掌握度 | 每个分类的 `correct / total × 100%` |

### 错误记录结构

```javascript
{
  pairNo: 26,
  categoryName: '时间、频率与时态',
  targetWord: 'postpone',
  targetSide: 'q',
  correctWords: ['delay', 'put off', 'defer', '推迟 / 延期'],
  userSelected: ['defer', 'immediately'],   // 用户选了什么
  missed: ['delay', 'put off', '推迟 / 延期'] // 遗漏了什么
}
```

## 六、错误追踪与重练

- **本轮错误面板**：每轮提交后简短显示对错
- **最终错误回顾**：所有轮次结束后，`errors[]` 完整列表展示
- **重练错题按钮**：仅当 errors 不为空时显示 → 从 errors 中提取 pair，重新组成新一局
- **分类掌握度**：实时按分类计算，帮助用户识别薄弱场景

## 八、陷阱词处理决策

**v1 范围**：陷阱词仅在大纲展示视图中作为参考卡片出现，不参与游戏。

原因：
- 陷阱词包含不同形态（数字对比、拼写提示、不可数名词），不适合统一的"同义词匹配"游戏机制
- 未来可在 v2 中增加"听写陷阱词"独立 quiz 模式

## 九、与现有模块的差异

| 维度 | Writing | Speaking | Listening |
|------|---------|----------|-----------|
| API 调用 | DeepSeek Chat | DeepSeek + Groq Whisper | **无** |
| 异步操作 | fetch × 1 | fetch × 2 (STT + AI) | **无** |
| Loading overlay | 有 | 有 | **无** |
| API Key 依赖 | DeepSeek Key | DeepSeek + Groq Key | **无** |
| 主要交互 | 文本输入 | 录音 | 点击 tile |
| 数据来源 | AI 实时生成 | AI 实时生成 | JS 常量嵌入 |
| 评分维度 | TA/CC/LR/GRA | FC/LR/GRA/P | 正确率/连对/分类掌握度 |
| 导出报告 | Markdown | Markdown | Markdown |
| 失败模式 | API 超时/JSON 截断 | STT 失败/评分超时 | N/A（无服务端依赖） |
