# 未来可能的优化方向

---

## 写作评分优化（现有）

如果测试中发现偏差仍偶发性超出 ±0.5，可考虑以下升级：

### 1. Few-Shot Anchoring（少样本锚定）

在 System Prompt 中附上 1-2 篇经过官方考官打分的样文及其评分，帮助模型校准评分标准。

### 2. 多阶段 Pipeline

- **Step 1**：先让 AI 做语法纠错和批注提取
- **Step 2**：将纠错报告 + 原文 + 量表再次送入 AI 进行最终评分
- 这种"先改后判"的逻辑更接近真人考官的阅卷流程

### 3. 缓存高频题目的评分结果

相同题目再次评分时参考历史数据，减少重复调用并提升一致性。

### 4. 写作 + 口语统一账号体系

利用 localStorage 记录用户历史评分，提供进步曲线和薄弱维度追踪。

## 口语评分优化（新增）

### 5. 多模态音频直接评分

当多模态模型（如 GPT-4o、Qwen3-Omni）成熟且免费额度足够时，将音频直接发送给模型进行评分，替代"STT 转写 + 文本评分"的二段式链路。优势：发音评分不再依赖间接推断，模型可以直接听到发音。

### 6. 多 Part 分段录音

当前仅支持单次整体录音。未来可扩展为 Part 1（问答）/ Part 2（独白）/ Part 3（讨论）三段独立录音，每段有针对性的评分。Part 3 还可引入"虚拟考官追问"的对话式体验。

### 7. 发音详细诊断

- 将音频分段与转写文本对齐，定位发音问题具体到单词
- 利用音素识别（phoneme recognition）检测特定音素错误
- 针对常见母语发音问题给出模式化建议（如中文母语者的 /θ/ → /s/ 替换）

### 8. 实时录音提示

录音过程中给出非侵入式提示（如"你刚才停顿了 3 秒，可以尝试继续说"），帮助考生实时调整。

### 9. 音视频录制

支持视频录制（MediaRecorder 可同时录制屏幕/摄像头），让考官看到考生的面部表情和肢体语言——虽然这些不直接影响评分，但可提供更完整的练习体验。

## 听力同义替换优化

### 14. 陷阱词独立 Quiz

将"时间与数字陷阱"、"单复数连读陷阱"、"专有名词拼写"三组陷阱词设计成听写式 quiz（播放音频 → 用户输入拼写）。

### 15. 多轮 / 多量适配

- 支持用户自定义每局轮数（10 / 15 / 20）
- 支持进阶模式：每次答错的词对在后续轮次中重新出现（间隔重复）

### 16. 难度分级

- 初级：仅显示英文 tile，target 也是英文
- 中级：中英混排（当前模式）
- 高级：全部中文 tile，target 是英文（反向翻译）

## 通用优化

### 17. 多语言支持

当前界面为中文，未来可增加英文界面切换，方便非中文用户。

### 18. PWA 离线支持

利用 Service Worker 实现 PWA，支持离线加载基础 UI（在线评分仍需网络）。

### 19. 评分历史 Dashboard

- 本地存储历次评分记录（localStorage JSON 数组）
- 可视化展示各维度分数趋势折线图
- 写作 vs 口语强弱项对比雷达图

### 20. 自定义评分标准

支持用户选择不同评分标准（如托福独立写作、剑桥 C1 Advanced 等），扩展工具适用场景。
