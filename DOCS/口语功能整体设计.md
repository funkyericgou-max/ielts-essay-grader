# 口语功能整体设计

## 一、功能概述

在现有 IELTS Essay Grader（写作批改）基础上，新增 **IELTS Speaking Grader（口语批改）** 模块。用户进入后选择 Writing 或 Speaking 入口，进入对应工作区。

### 核心链路

```
用户录音 (MediaRecorder API)
  → 前端音频分析 (Web Audio API: WPM / 停顿 / 音量变化)
  → STT 转写 (Groq Whisper API, 免费)
  → 转写文本 + 音频元数据 → DeepSeek Chat API (评分)
  → 渲染口语评分结果 (FC / LR / GRA / P)
```

### 为什么选 Groq Whisper

| 对比维度 | Groq Whisper | 浏览器 Web Speech API | OpenAI Whisper |
|---------|-------------|---------------------|----------------|
| 费用 | **无限免费** | 免费 | 付费 ($0.006/min) |
| 中文准确度 | **高** | 一般 | 很高 |
| 英文准确度 | **很高** | 高(Chrome) | 很高 |
| 速度 | **极快** (LPU 芯片) | 实时 | 快 |
| API Key | 免费注册即得 | 无需 | 需要绑卡 |
| 语言支持 | 50+ 种 | 取决于浏览器 | 50+ 种 |

## 二、音频录制方案

### 技术选型：MediaRecorder API

```javascript
// 浏览器原生，零依赖
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
const mediaRecorder = new MediaRecorder(stream, {
  mimeType: 'audio/webm;codecs=opus'  // 或 audio/mp3
});
const chunks = [];
mediaRecorder.ondataavailable = (e) => chunks.push(e.data);
mediaRecorder.onstop = () => {
  const audioBlob = new Blob(chunks, { type: 'audio/webm' });
  // 发送给 Groq Whisper
};
```

### 音频格式要求

| 参数 | 推荐值 | 原因 |
|------|--------|------|
| 编码格式 | WebM (Opus) 或 WAV | Groq Whisper 支持 WebM/WAV/MP3/FLAC |
| 采样率 | 44100 Hz 或 48000 Hz | 标准音频采样率 |
| 声道 | 单声道 (Mono) | 语音识别只需单声道 |
| 位深 | 16 bit | 标准位深 |
| 最大文件 | 25 MB | Groq Whisper API 限制 |

## 三、前端音频分析

在发送 STT 之前，前端利用 Web Audio API 对原始音频进行本地分析，提取元数据。

### 分析指标

```javascript
// 使用 AudioContext + AnalyserNode 提取
const audioContext = new AudioContext();
const analyser = audioContext.createAnalyser();
analyser.fftSize = 2048;

// 分析维度：
// 1. 录音总时长 (秒)
// 2. 语速 (WPM): 转写后词数 / 时长分钟
// 3. 停顿检测: 振幅低于阈值的连续片段 (>0.5s 计为一次停顿)
// 4. 停顿总时长 / 占比
// 5. 音量标准差 (反映语调变化幅度)
// 6. 有效语音段占比 (去除首尾静音)
```

### 停顿检测算法

```
对 PCM 数据按 100ms 窗口分帧
→ 计算每帧 RMS (均方根振幅)
→ 如果连续 5 帧 RMS < 阈值(平均RMS的15%) → 标记为一次停顿
→ 停顿持续时长 = 帧数 × 0.1s
→ 仅统计 > 0.5s 的停顿
```

### 数据打包

音频元数据以 JSON 格式打包，传入 User Prompt：

```json
{
  "duration_seconds": 92,
  "word_count": 187,
  "wpm": 122,
  "pause_count": 8,
  "pause_total_duration": 4.2,
  "pause_ratio": 0.046,
  "volume_variance": 0.34,
  "filler_words": { "um": 3, "uh": 2, "you_know": 1 },
  "self_corrections": 2,
  "ttr": 0.62,
  "avg_sentence_length": 14.3
}
```

## 四、STT 转写（Groq Whisper）

### API 调用

```javascript
// Groq Whisper API
const formData = new FormData();
formData.append('file', audioBlob, 'recording.webm');
formData.append('model', 'whisper-large-v3');
formData.append('language', 'en');  // 可设为 auto 自动检测
formData.append('response_format', 'verbose_json');
// verbose_json 返回: { text, segments[{start, end, text}], language }

const response = await fetch('https://api.groq.com/openai/v1/audio/transcriptions', {
  method: 'POST',
  headers: { 'Authorization': `Bearer ${groqApiKey}` },
  body: formData
});
```

### API Key 管理

- 用户通过设置弹窗输入 Groq API Key
- 存储在 `localStorage.getItem('groq_api_key')`
- Groq Key 注册地址：[console.groq.com](https://console.groq.com)（免费注册，无需绑卡）
- 与 DeepSeek Key 分开管理，互不影响

### 转写结果处理

- `verbose_json` 模式返回带时间戳的分段结果
- `segments[].start` / `segments[].end` 用于定位停顿位置
- 若不使用 `verbose_json`，返回纯文本，停顿仍由前端音频分析完成

## 五、评分 Prompt 设计

详见 [DOCS/Prompt工程与设计.md](Prompt工程与设计.md) 口语部分。

核心要点：
- System Prompt 动态注入口语 Band Descriptors
- 与写作相同的 CoT 三步推理法（定档→微调→举证）
- 音频元数据作为硬约束传入，AI 综合推断 P 维度
- P 维度评分依赖元数据 + 转写文本中的语音特征推断

## 六、口语结果展示

### Tab 设计

| Tab | 内容 | 数据来源 |
|-----|------|---------|
| **评分总览** | 题目分析卡片、4 维度评分卡片（FC/LR/GRA/P） | `evaluation_justification` + `prompt_analysis` |
| **转写批注** | 带标注的完整转写文本，高亮口语问题 | `transcript_annotated` |
| **语法分析** | 可折叠语法问题列表 | `grammar_issues_list` |
| **流利度分析** | 语速曲线、停顿分布、填充词统计的**可视化图表** | 前端音频元数据 + `feedback.fluency_analysis` |
| **详细反馈** | 优缺点 + 流利度诊断 | `feedback` |
| **行动建议** | 3 条精准改进建议 | `next_steps` |

### 流利度分析 Tab（新增可视化）

这是一个口语独有的 Tab，展示从音频中提取的量化指标：

- **语速仪表盘**：可视化当前 WPM vs 理想区间 (120-150 wpm)
- **停顿分布图**：时间轴 + 停顿标记
- **填充词饼图**：各类填充词的占比
- **与 Band Score 的关联解释**："你的语速 122 wpm 处于正常范围，但 8 次停顿（平均每 11.5 秒一次）表明流利度有提升空间，建议减少 thinking pauses"

## 九、关键风险

| 风险 | 程度 | 应对 |
|------|------|------|
| STT 转写错误导致评分偏差 | **中** | Whisper large-v3 准确度高；转写文本与音频一起展示供人工核对 |
| 发音评分依赖间接推断 | **高** | 明确标注"发音评分为 AI 基于音频特征推断，仅供参考" |
| Groq API 未来可能收费 | 低 | 架构预留切换 STT 提供商的能力 |
| 录音文件过大 | 低 | 前端压缩音频；Groq 限制 25MB，正常 2 分钟口语远低于此 |
| 浏览器兼容性 | 中 | MediaRecorder 在现代浏览器中普遍支持；移动端 Safari 需额外测试 |
