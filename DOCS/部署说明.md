## 部署方式

1. 代码推送到 `main` 分支
2. GitHub Actions 自动构建并部署到 GitHub Pages
3. 访问 https://funkyericgou-max.github.io/ielts-essay-grader/ 即可使用

## 首次部署配置

1. 在 GitHub 上创建仓库 `ielts-essay-grader`
2. 在仓库 Settings → Pages 中启用，Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 推送代码后等待约 1-2 分钟完成部署

## 安全注意事项

- DeepSeek API Key 和 Groq API Key 通过浏览器 `localStorage` 存储，**永远不会上传到 GitHub**
- `.gitignore` 已排除 `key.txt`、`advice.txt` 等敏感文件
- **首次访问时**页面会弹出友好的 API Key 引导窗口，用户可选择「暂不设置」跳过
- 用户使用 Writing/Speaking 提交批改时才需要对应的 Key（按需提示）
- 右上角始终保留 `⚙ 设置` 入口，随时可以配置或更换 Key
- Listening 模式无需任何 Key，即开即玩
